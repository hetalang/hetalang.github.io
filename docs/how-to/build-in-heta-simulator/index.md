## Работа с HetaSimulator.jl в режиме компилятора

- можно использовать все возможности heta-compiler прямо из Julia, без командной строки
- heta-compiler как отдельное приложение можно не устанавливать, меньше согласований версий
- проще переключаться между версиями компилятора, если вы работаете в Julia
- можно иметь несколько версий компилятора в разных проектах (если используете локальное окружение)

`heta_version()` - выдает версию компилятора, которая встроена в HetaSimulator.jl. Аналогично `heta --version` в командной строке.

`heta_init(".")` - инициализация модельной платформы в текущей директории. Создает файлы для начала работы. Аналогично `heta init` в командной строке.

`heta_build("."; units_check = true)` - компилирует модель в текущей директории и экспортирует файлы в соответсвие с platform.yml. Аналогично `heta build --units-check` в командной строке.

Более подробно тут https://hetalang.github.io/HetaImporter.jl/dev/api/#Heta-Compiler-CLI

Прочее

`] status HetaSimulator` - информация о версии симулятора.
`] add HetaSimulator` - установка последней версии симулятора.
`] add HetaSimulator@0.8.3` - установка конкретной версии симулятора.
